数字工牌 · 安装与使用

一、包里有什么
  firmware/FoloToy-AI-Passport-full.bin   固件整机合并镜像(ESP32-C3 / 8MB Flash)
  server/badge_server.py                  后台服务(Python 3.8+,零第三方依赖)
  server/config.example.json              配置模板
  server/run_server.bat                   Windows 一键启动
  封面.png                                玩法社区发布用封面

二、准备
  1. Python 3.8 以上,Windows 建议 3.10 及以上。
  2. 一块 FoloToy AI Passport(ESP32-C3 / 8MB Flash)。
  3. 电脑与工牌连接同一个 Wi-Fi。
  4. 可选:阿里云百炼 API Key(不填则走模拟转写与模拟分析)。
  5. 可选:飞书自建应用与多维表格(不填则只在本地留记录,不推送群消息)。

三、刷写固件
  1. 用玩法社区的安装流程,或用 esptool 把 firmware/FoloToy-AI-Passport-full.bin 写入 0x0。
  2. 整机镜像写 0x0 会清空设备已存的 Wi-Fi 配置,刷完后按第五步重新配置。

四、启动后台
  1. 双击 server/run_server.bat,窗口第一屏会打印本机地址,例如 http://192.168.1.100:8000。
  2. 首次运行自动生成 config.json:填入 asr_api_key 与 llm_api_key(填写同一个百炼 Key),
     需要在飞书群收纪要时再填 feishu_ 开头的四项。
  3. 浏览器打开 http://本机IP:8000/recordings 可查看录音、纪要、待办与销售评分。

五、配置工牌
  1. 工牌待机页按 DOWN 进入配网页,屏幕显示热点名 FoloBadge-XXXX。
  2. 手机连这个热点,用手机浏览器打开 192.168.4.1。
  3. 填后台地址(填第四步窗口里的地址),需要换网络时同时填 Wi-Fi 名称与密码,点"保存并重启"。
  4. 重启后工牌连上 Wi-Fi,待机页右上角 Wi-Fi 图标变绿。

六、日常使用
  1. 待机页按 OK 开始录音,再按 OK 结束上传;按 UP 取消并丢弃本次录音。
  2. 后台自动转写,生成纪要、待办、销售五维评分,并把纪要卡片推到飞书群。
  3. 工牌按 UP 查看最近一次录音的待办;飞书卡片里点"认领"或"误提"处理待办。

七、常见问题
  - 任务页一直显示"暂无任务":确认后台地址填对(端口 8000),并放行电脑 8000 端口防火墙。
  - 录音后没有纪要:确认 config.json 里的密钥有效,后台窗口会打印失败原因。
  - 转写返回无有效语音:录音过短或环境无人声,重新录一段再试。
